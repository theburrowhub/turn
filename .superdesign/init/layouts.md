# Existing layouts

Turn is a desktop control surface with four stable regions:

1. A global toolbar across the top.
2. A fixed left navigator containing search, filters, and the hierarchical workspace/session/process tree.
3. A right work area containing a small session context bar and the exact selected node's WorkSurface.
4. A single-line status bar fixed to the bottom for transient errors and operational feedback.

Modal sheets are centered over the same window for workspace, session, layout, rename, relationship, and context-handoff tasks. The application favors dense information, low pointer travel, and keyboard operation. The left tree is the sole control plane; selecting a semantic child changes the right side to that child's unique surface.
